## ✨ 功能特性

### 📚 首页浏览

- **瀑布流卡片墙** — 精美封面展示，悬停动效
- **智能搜索** — 支持标题、系列名模糊搜索（防抖 250ms）
- **分类筛选** — 多系列一键筛选，带搜索功能
- **排序功能** — 按标题升降序、页数多少排序
- **随机推荐** — 🎲 随机推荐一本，发现新惊喜
- **收藏系统** — ❤️ 点击卡片即可收藏，导航栏快速查看
- **最近阅读** — 🕐 记录最近阅读记录
- **阅读进度** — 每本书自动保存页码，下次打开继续

### 🎧 音频播放器

- **音频时间轴同步** — 根据时间点自动切换图片，完美匹配朗读节奏
- **流畅翻页动画** — CSS transform 动画效果
- **缩略图导航条** — 底部页面缩略图，点击跳转任意页
- **播放控制** — 播放/暂停、快进后退 10 秒、进度条拖拽
- **倍速调节** — 0.5x ~ 2.0x 可调播放速度
- **沉浸模式** — 图片填满屏幕，自动隐藏控件
- **键盘快捷键** — 空格播放暂停、←→翻页、Esc 退出、F 沉浸模式
- **触摸滑动** — 移动端左右滑动手势翻页
- **自动连播** — 播放完一本后提示并自动播放下一本

### 🎨 视觉设计

- **三套主题** — 亮色 / 暗色 / 护眼（Sepia）一键切换
- **玻璃态导航栏** — `backdrop-filter: blur(20px)` 毛玻璃效果
- **精致动画** — 卡片入场动画、悬停缩放、按钮反馈
- **响应式布局** — 完美适配桌面、平板、手机

### 💾 数据持久化

| 数据 | 存储方式 | 说明 |
|------|---------|------|
| 收藏列表 | localStorage | 跨会话保留 |
| 最近阅读 | localStorage | 最多 50 条 |
| 阅读进度 | localStorage | 每本书独立记录 |
| 主题偏好 | localStorage | 下次自动应用 |

## ⚙️ 配置说明

只需修改 **一个文件**：`config.json`

```json
{
  "booksDir": "D:\\绘本",
  "port": 3000,
  "_comment": "⚙️ 只需修改 booksDir 为你的绘本目录路径"
}
```

所有程序都会自动读取此配置：
- ✅ `server.js` — 自动读取
- ✅ `scanner.py` — 自动读取
- ✅ `start.bat` — 自动读取

### 在其他电脑部署

1. 复制整个 `cartoon-books` 文件夹
2. 编辑 `config.json`，修改 `booksDir` 为你的绘本目录路径
3. 双击 `start.bat` → 选择 `1` 启动服务

> 💡 首次使用需要先执行一次 `[4] 扫描/更新数据` 生成索引文件。

## 📥 添加新绘本

### 1. 准备绘本文件夹

将新的绘本放入你的绘本目录，确保包含：

```
你的绘本/
└── 序号_系列 标题/
    ├── 封面.jpg           # 可选，没有则用第一张内页
    ├── 01.jpg             # 内页图片（按顺序编号）
    ├── 02.jpg
    ├── ...
    ├── xxx.mp3            # 可选，音频文件
    └── xxx_时间.txt       # 可选，音频同步时间轴
```

### 2. 时间轴格式（可选）

如果需要音频同步翻页，创建 `*_时间.txt` 文件：

```
01.jpg,0:00.000-0:08.401
02.jpg,0:08.401-0:38.623
03.jpg,0:38.623-1:40.667
...
```

格式：`图片名,开始时间-结束时间`

### 3. 更新索引

运行扫描脚本更新数据：

```bash
python scanner.py
```

或者通过启动菜单选择 `[4] 扫描/更新数据`

### 4. 重启服务

刷新浏览器或重启服务器即可看到新内容。

## ❓ 常见问题

**Q: 提示 "加载失败" 怎么办？**

A: 必须通过 HTTP 服务访问，不能直接双击打开 index.html。请使用 `start.bat` 启动服务后再访问。

**Q: 图片/音频无法显示？**

A: 检查 `config.json` 中的 `booksDir` 路径是否正确指向你的绘本目录。

**Q: 如何更换端口？**

A: 修改 `config.json` 中的 `"port"` 值。

**Q: 扫描很慢？**

A: 正常现象，需要遍历所有图片和音频文件。首次完成后后续会快很多。
