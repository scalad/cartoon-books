# 📖 阅读世界 | 绘本 + 视频

> 本地运行的中文绘本阅读与英语视频学习站点：绘本支持音频同步翻页、收藏与进度；视频支持列表连播、全屏与观看进度。单页前端 + Node 静态服务 + Python 扫描，无框架依赖。

## ✨ 功能特性

### 📚 绘本模式（首页「📖 绘本」）

- **卡片墙** — 封面展示，悬停动效
- **搜索** — 标题、系列名模糊搜索（防抖）
- **系列筛选** — 下拉可搜可选
- **排序** — 标题、页数等
- **随机推荐** — 从当前筛选结果中随机一本
- **收藏 / 最近观看** — 导航栏快捷筛选
- **阅读进度** — 每本书保存页码，下次继续

### 🎧 绘本播放器

- **音频时间轴** — `*_时间.txt` 与图片页面对应，自动翻页
- **缩略图条、倍速、快进快退、沉浸模式**
- **快捷键** — 空格播放/暂停，←→ 翻页，Esc 退出，F 沉浸模式
- **触摸滑动** — 移动端左右滑动翻页
- **连播** — 当前列表播放结束后可提示并自动下一本

### 🎬 视频模式（首页「🎬 视频」）

- **网格卡片** — 缩略图懒加载首帧
- **搜索 / 系列筛选 / 排序**（含按文件大小）
- **收藏、最近观看、观看历史**（与绘本共用历史面板，按模式切换）
- **视频播放器**
  - 打开视频后自动进入**浏览器全屏**，关闭播放器时退出全屏（便于完整看到原生控件与自定义按钮）
  - **播放列表**（同系列或当前筛选列表）
  - 顶部栏：收藏、全屏、列表；画面侧有全屏与列表快捷按钮
  - **快捷键** — Esc 关闭，空格播放/暂停，←→ 快进/快退 5s，↑↓ 音量，F 切换全屏，N 下一个视频

### 🎨 视觉与数据

- **三套主题** — 亮色 / 暗色 / 护眼（Sepia）
- **响应式布局** — 桌面与移动端可用
- **localStorage** — 收藏、最近、阅读/观看进度、主题、模式等

## 🚀 快速开始

### 方式一：一键启动（Windows，推荐）

双击或命令行执行：

```bash
start.bat
```

启动菜单示例（以脚本实际输出为准）：

- `[1]` 启动服务并打开浏览器  
- `[2]` 重启服务  
- `[3]` 停止服务  
- `[4]` 扫描/更新数据（**绘本 + 视频**）  
- `[5]` 打开浏览器  
- `[6]` 打开绘本目录  
- `[7]` 打开视频目录  
- `[Q]` 退出  

### 方式二：手动启动

```bash
# 1. 生成索引（首次或更新媒体文件后）
python scanner.py

# 2. 启动 HTTP 服务（视频大文件需走服务，且支持 Range）
node server.js

# 3. 浏览器访问
http://localhost:3000
```

> 请勿直接双击打开 `index.html` 使用（`books.json` / `videos.json` 与媒体路径依赖本地服务）。

## 📁 项目结构

```
cartoon-books/
├── config.json          # 绘本目录、视频目录、端口（唯一需改的配置）
├── index.html           # 单页前端（绘本 + 视频 UI）
├── server.js            # Node 静态服务：/videos/* → 视频目录，其余 → 应用目录与绘本目录
├── scanner.py           # 扫描绘本 → books.json，扫描视频 → videos.json
├── start.bat            # Windows 启动与菜单
├── start.sh             # macOS/Linux 启动脚本（若存在）
├── books.json           # 扫描生成的绘本索引
├── videos.json          # 扫描生成的视频索引
└── README.md

你的绘本目录/             # config.json 中 booksDir
├── 序号_系列 标题/
│   ├── 封面.jpg
│   ├── 01.jpg …
│   ├── *.mp3
│   └── *_时间.txt

你的视频目录/             # config.json 中 videosDir（可与绘本目录分离；若在绘本目录内，扫描绘本时会自动跳过）
└── …                     # 见 scanner 内规则与生成的 videos.json
```

## ⚙️ 配置说明

编辑 **`config.json`**：

```json
{
  "booksDir": "D:\\绘本",
  "videosDir": "D:\\绘本\\视频",
  "port": 3000,
  "_comment": "booksDir = 绘本根目录；videosDir = 视频根目录（可选，若在 booksDir 内会自动跳过以免重复扫描）"
}
```

- **`booksDir`**：绘本资源根目录（图片、音频、时间轴文件）。  
- **`videosDir`**：视频根目录；不配置或留空则仅绘本功能可用（可不生成 `videos.json` 或扫描跳过视频）。  
- **`port`**：HTTP 端口，默认 `3000`。

更换电脑：复制整个项目 → 改 `config.json` → 运行 `[4]` 扫描 → `[1]` 启动。

## 📥 添加新绘本

1. 在 `booksDir` 下按现有规则新建文件夹（含内页 `*.jpg` 等）。  
2. 可选：`封面.jpg`、`.mp3`、`*_时间.txt`（格式：`图片名,开始时间-结束时间`）。  
3. 执行 `python scanner.py` 或通过 `start.bat` 选 `[4]`。  
4. 刷新页面或重启 `node server.js`。

---

## 🎬 添加新视频

1. 将视频文件放入 `videosDir` 下（目录层级与命名规则以 `scanner.py` 为准，扫描后会写入 `videos.json`）。  
2. 执行扫描更新 `videos.json`。  
3. 刷新页面。  

视频通过站点路径 `videos/...` 由 `server.js` 映射到本地 `videosDir`（支持 Range，适合 MP4 在线播放）。

## ❓ 常见问题

**Q: 页面提示加载失败？**  
A: 必须通过 `http://localhost:端口` 访问；先执行 `node server.js`（或 `start.bat`）。

**Q: 图片或音频打不开？**  
A: 检查 `booksDir` 是否正确，扫描是否已执行，路径中尽量使用英文或确认服务能访问该盘符。

**Q: 视频黑屏或无法拖动进度？**  
A: 确认已用本项目的 `server.js` 提供文件（支持 Range）；直接 file 协议打开页面无法正确播放大文件。

**Q: 如何改端口？**  
A: 修改 `config.json` 的 `port`。

**Q: 扫描很慢？**  
A: 绘本与视频较多时首次扫描会耗时较长，属正常现象。
